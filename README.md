🧮 Responsive Calculator

A modern, responsive calculator built using HTML, CSS, and JavaScript. It supports keyboard input, button clicks, and full mathematical expression evaluation with input validation and error handling.

✨ Features
⌨️ Keyboard input support for numbers and operators.
➕ Supports addition, subtraction, multiplication, division, and modulus.
🧮 Evaluates complete mathematical expressions.
⌫ Backspace support for deleting input.
✅ Enter key support for calculating results.
⚠️ Invalid key detection and error handling.
🛡️ Safe division-by-zero handling.
📱 Responsive design for desktop, tablet, and mobile devices.
🎨 Clean and modern user interface.
🛠️ Technologies Used
HTML5 – Semantic structure.
CSS3 – Styling, Flexbox, and media queries.
JavaScript – Keyboard events, mathematical functions, and input validation.

🚀 How to Run
Clone this repository:
   git clone YOUR_GITHUB_REPOSITORY_URL

Open the project folder.
Open index.html in your web browser.
Start calculating using your keyboard or the on-screen buttons.
⌨️ Keyboard Shortcuts
Key	Action
0–9	Enter numbers
+, -, *, /, %	Mathematical operations
Enter	Calculate the result
Backspace	Delete the last character

Unsupported keys trigger a warning message.
